# Grade 5 Revision Book

Interactive English and Science revision for one student. Practice and Exam modes, English and Arabic explanations, read-aloud buttons, and it works offline.

- Open the page, then use Share, then Add to Home Screen on iPad.
- To update: edit `index.html`, then change `VERSION` in `sw.js` so devices pick up the new copy.
- Pages are marked `noindex` so search engines should not list them.
